# Игра «Угадай число» на Go 🎲

Консольная игра на языке Go, в которой игроку нужно угадать случайное число за ограниченное количество попыток.

## Реализованный функционал

- Генерация случайного числа в заданном диапазоне.
- Ограниченное количество попыток на раунд.
- Подсказки после каждого хода («больше» или «меньше»).
- Защита от некорректного ввода (буквы и пустые строки не ломают программу и не тратят попытки).
- Подсказки по расстоянию («Горячо», «Тепло», «Холодно»).
- Выбор уровня сложности: Easy, Medium, Hard.
- История введённых чисел и повтор игры без перезапуска.
- Сохранение статистики игр в `results.json`.

## Используемые технологии

- **Язык:** Go (версия 1.22+)
- **Стандартная библиотека:** `fmt`, `math/rand/v2`, `bufio`, `os`, `strconv`, `strings`

## Как запустить

1. Склонировать репозиторий и перейти в папку проекта:
   ```bash
   git clone https://github.com/peresvet668/Module_1
   cd репозиторий
   ```
2. Запуск игры:
   ```bash
   go run main.go
   ```
