Проект. Модуль 1 — Игра «Угадай число»
Игра "Угадай число" на Go
-
Используется:
Базовые пакеты: `fmt`, `math/rand` , `time`; 
для ввода `bufio` + `os` и ``strconv``, для results.json — `encoding/json` 

---

Простая консольная игра, в которой игроку нужно угадать случайное число от 1 до 100 за ограниченное количество попыток. 
Реализуем по приницпу  итеративной разработки. Сначала основа из ТЗ - а дальше фичи.



-------
Запуск игры:
`go run main.go`

Игра записывает данные в `.json`-файл
